# Power BI Assignment 2 – DAX & Data Visualization

## E-Commerce Sales Analysis

### 📌 Project Overview
This project focuses on analyzing e-commerce sales data using **Microsoft Power BI**. The objective is to explore sales performance, profitability, sales trends, and target achievements using DAX (Data Analysis Expressions) and interactive data visualizations.

### 📂 Dataset
The project uses the following datasets:

- `List of Orders.csv`
- `Order Details.csv`
- `Sales target.csv`

### 🛠️ Tools & Technologies
- Microsoft Power BI
- DAX (Data Analysis Expressions)
- Data Modeling
- Data Visualization

### 📊 Tasks Performed

#### 1. Calculated Columns
- Created a **Category Type** column by combining Category and Sub-Category.
- Calculated Revenue per Order using Amount × Quantity.
- Created a **Sales Category** column to classify sales as Above Average or Below Average.

#### 2. Calculated Measures
- Calculated the total Order Count.
- Calculated Average Profit in Delhi.
- Created a Year-to-Date (YTD) Sales measure.

#### 3. Data Visualization
Created the following visualizations to analyze e-commerce sales performance:

- **Clustered Column Chart:** Sales Target Achievement by Category.
- **Donut Chart:** Maximum Profit Margin by Sub-Category.
- **Line Chart:** Monthly Sales Trend.
- **Scatter Chart:** Comparison of Profit and Quantity by Sub-Category.
- **Cards:** Total Sales Amount and Sales Target.
- **Multi-Row Card:** Minimum Target for Each Segment.
- **Matrix:** Sales Performance across Categories and Months.
- **Map:** Geographic Sales Analysis by City.
- **Treemap:** Sales Distribution by Sub-Category.
- **Funnel Chart:** Order Count Analysis by State.

### 🎯 Learning Outcomes
- Understanding data modeling and table relationships.
- Applying DAX formulas to create calculated columns and measures.
- Analyzing sales and profitability metrics.
- Creating interactive and meaningful Power BI visualizations.
- Identifying sales trends and regional performance.
