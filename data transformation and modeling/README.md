# Power BI Assignment 1 – E-Commerce Sales Analysis

## Project Overview
This project focuses on exploring and analyzing e-commerce sales data using Microsoft Power BI. It covers data transformation, data cleaning, merging, grouping, aggregation, and data modeling.

## Tools Used
- Microsoft Power BI Desktop
- Power Query Editor
- CSV Files

## Dataset
The project uses three datasets:
- List of Orders
- Order Details
- Sales Target

## Tasks Performed

### 1. Data Import
- Imported three CSV files into Power BI.
- Loaded the datasets into Power Query Editor.

### 2. Data Transformation
- Kept the first 500 rows from List of Orders.
- Changed data types of relevant columns.
- Converted customer names into proper case.
- Merged City and State into a Location column.
- Created a Profit Margin column.
- Created a Profit Status column using conditional logic.

### 3. Data Merging
- Merged List of Orders and Order Details using Order ID.
- Created a combined table named Orders Data.

### 4. Data Cleaning
- Checked for missing values using Column Quality.
- Checked and removed completely identical duplicate rows where applicable.

### 5. Sorting and Filtering
- Sorted orders by Order Date in descending order.
- Applied filters for regional analysis.

### 6. Grouping and Aggregation
- Calculated the count of orders by Order ID.
- Aggregated sales targets by month.

### 7. Data Modeling
- Established relationships between List of Orders and Order Details using Order ID.
- Established a relationship between Order Details and Sales Target using Category.

## Key Learning Outcomes
- Understanding Power Query and data transformation.
- Handling missing and duplicate data.
- Performing joins and aggregations.
- Understanding relationships between tables.
- Developing practical data modeling skills in Power BI.
